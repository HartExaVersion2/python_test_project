# Замер скорости скачивания

Скрипт `measure_speed.py` скачивает один и тот же файл 10 раз подряд и считает скорость по фактическому объёму данных и времени запросов.

## Что нужно

Python 3.9 или новее. Сторонние пакеты не нужны.

Проверка, что интерпретатор установлен и доступен из терминала:

```powershell
python --version
```

Если команда отвечает `Python was not found`, Python не установлен. Скачайте его с [python.org](https://www.python.org/downloads/) и при установке включите **Add python.exe to PATH**. После установки откройте новое окно терминала.

## Запуск

Откройте терминал в папке со скриптом и передайте адрес файла:

```powershell
python measure_speed.py "https://example.com/big-image.jpg"
```

Адрес обязателен. Подойдёт прямая ссылка на тяжёлую картинку или другой файл, который сервер отдаёт целиком. Ссылка должна открываться без логина.

Без адреса скрипт печатает подсказку и завершается:

```text
Использование: python measure_speed.py "https://example.com/big-image.jpg"
```

## Что печатается

По каждому из 10 запросов — время до полной загрузки и размер ответа:

```text
Запрос 1: 1.23 с, 5.00 МБ
...
Запрос 10: 1.18 с, 5.00 МБ

Среднее время запроса: 1.20 с
Скачано данных: 50.00 МБ (52428800 байт)
Скорость: 4.17 МБ/с
```

Скорость считается так: весь скачанный объём делится на суммарное время десяти запросов. В расчёте 1 МБ = 1024 × 1024 байт.

Запросы идут по очереди: следующий начинается только после того, как предыдущий файл скачан до конца. К адресу добавляется уникальный параметр, чтобы ответ не взялся из кэша.

## Если запрос не удался

Скрипт останавливается и пишет причину:

- код ответа сервера, например `Запрос 3 завершился с кодом 404`;
- ошибку соединения, например `Запрос 1 не удался: ...`.

Проверьте, что ссылка открывается в браузере и ведёт сразу на файл.
